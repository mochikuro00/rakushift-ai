> 最終更新: 2026年7月6日 (v3.7.228)
> 用途: AI（Claude / ChatGPT / Gemini）や Canva AI 等に貼り付けて、営業資料・マニュアル・LP を生成するためのプロンプト集。

## 0. システム解析（現行の全体像）— プロンプトに使う正確な情報

### サービス概要
- **ラクシフトAI**：AI（数理最適化）がシフトを自動作成するクラウド型シフト管理SaaS。
- キャッチ：**「ボタン1つで、シフト作成がおわる。」**
- 対象：飲食・小売・医療介護・サービス業など、シフト制の店舗全般。スマホ完全対応。

### 使い方は「3ステップ」
| STEP | 画面 | 内容 |
|---|---|---|
| **STEP1 店舗設定** | 店舗設定 | 営業時間・定休日（24時間営業対応）／シフトパターン（早番・遅番・夜勤等）／必要人数／休憩ルール／役職ロール |
| **STEP2 スタッフ管理** | スタッフ管理 | 役職・評価・給与形態・勤務条件（週/月の最低最大日数・連勤上限・最大労働時間）・該当パターン・休み希望 |
| **STEP3 AIシフト作成** | AIシフト作成 | ボタン1つで自動生成 → プレビュー確認 → 確定保存 |

### AIエンジン（差別化ポイント）
- **数理最適化（MILP：PuLP＋CBCソルバー）** を主軸に、Tier3（品質）→Tier2（カバレッジ）→Tier1（緊急）→グリーディの多段方式。
- **決定論的生成**：同じ入力なら毎回同じ結果（PC/スマホでも同一）。
- **緊急モード回避**：無理な設定でも数理的に解けるよう最低出勤日数をソフト制約化。荒れたシフトになりにくい。
- **労働基準法を自動遵守**：連続勤務上限（週1休）・勤務間インターバル10時間・休憩の自動付与。
- **翌休（夜勤2連勤防止）**：夜勤パターンの翌日を自動で休みに（ハード制約・全経路で厳守）。

### 主要機能（現行）
| 分類 | 機能 |
|---|---|
| シフトパターン | 早番/遅番/夜勤等の時間＋曜日別必要人数。**必要人数はパターン合計から自動計算**。 |
| 管理者配置 | パターンごとに「管理者（店長/リーダー）を何人入れるか」を指定（＝あけしめ責任者の確保） |
| 翌休 | 夜勤の翌日を自動でお休みに（夜勤連勤防止） |
| 過剰配置トグル | OFF＝必要数ぴったりで人件費抑制／ON＝多めに入れて全員の出勤日数を確保 |
| 給与形態の最適化 | 月給＝固定費として優先配置／時給＝調整役。OFF時は月給優先＋時給も多めに使う |
| 役職・評価 | 役職の「管理者」ONでメンター/管理者扱い。評価Dは新人としてメンターと同時間帯に配置（OJT） |
| シフト表 | 表/カレンダー表示・役職順ソート・ドラッグで手直し・**A4印刷/PDF保存（スマホ対応）** |
| 不足の原因分析 | 「不足N名」セルをクリックで、入れられない理由（NG曜日/希望外/上限到達等）を表示 |
| 生成プレビュー | 保存するまで本番反映なし。何度でも作り直せる |
| 分析レポート | 人件費推移・スタッフ別コスト構成・**出勤日数の内訳（日勤/夜勤別）** |
| 休み希望 | スタッフが提出 → 管理者が承認 → AIが自動で除外 |
| お知らせ | 運営/店舗からの連絡掲示・既読管理 |
| 本部管理モード | 複数店舗を本部から横断で「登録→一覧→閲覧」（閲覧専用）。プラン・スタッフ数も表示 |
| セキュリティ | 契約ID＋パスワード＋**セカンドPIN認証**。責任者引き継ぎ手順つき |

### 料金プラン
| プラン | 対象 | スタッフ上限 | 主な機能 |
|---|---|---|---|
| Standard | 小規模店舗 | 〜10名 | AIシフト作成・シフト表・休み希望 |
| Pro（人気） | 中規模店舗 | 〜50名 | Standard＋分析レポート・各種かしこい機能 |
| Premium | 大規模・多店舗 | 無制限 | Pro＋本部管理モード・優先サポート |

## 共通デザイン指針（すべての資料で守ること）

- **メインカラー：青**（`#2563eb` / `#3b82f6`）… ヘッダー・見出し・主要ボタン・強調
- **サブカラー：オレンジ**（`#f97316` / `#f59e0b`）… アクセント・注目ポイント・STEPバッジ・グラフの対比
- 背景は白基調、文字は濃いグレー（`#1f2937`）。青とオレンジの2色で統一感を出す。
- **馬鹿でもわかる**：専門用語は避け、1文を短く。アイコン・図・箇条書き中心。
- **必ず入れる視覚要素**：
  - **スクリーンショット**（後述の8枚を該当ページに配置）
  - **表**（機能一覧・料金・設定項目など）
  - **グラフ**（棒/円/折れ線。Chart.js または画像）
- A4横スライド（プレゼン）または A4縦（リーフレット）。1ページ1メッセージ。

## 2. 操作マニュアル（導入後のお客様向け）

```
あなたはSaaSの操作マニュアルを作るテクニカルライターです。
「ラクシフトAI」の操作マニュアルを、ITが苦手な店長でも分かるように作成してください。

【デザイン】メイン青・サブオレンジ。各手順にスクリーンショットを添え、表で要点整理。
【全体の流れ】シフトは「3ステップ」で作ります。この順番で章立てしてください。

STEP1 店舗設定（07_shop_settings.png）
  - 営業時間・定休日（24時間営業はチェックON）
  - シフトパターン（早番/遅番/夜勤の時間と、平日/土曜/日祝の必要人数。0でその曜日は不使用）
  - 管理者の配置人数（あけしめを店長/リーダーに任せたい時はON＋人数1以上）
  - 翌休（夜勤パターンでON＝翌日自動休み）
  - 過剰配置トグル（OFF＝ぴったり/ON＝多め）
  - 休憩ルール（○時間超で△分休憩）
STEP2 スタッフ管理（03_staff_management.png）
  - 役職（管理者ONでメンター/管理者）、評価（Dは新人=メンターと同時間帯）
  - 給与形態（月給=優先配置/時給=調整役）
  - 勤務条件（週/月の最低最大出勤日数・連勤上限・最大労働時間）
  - 該当シフトパターン、休み希望
STEP3 AIシフト作成（05→06）
  - 「AIシフト作成」→作成範囲を選ぶ→実行→プレビュー確認→「確定して保存」
  - 「不足」が出たらセルをクリックして原因を確認
その他: シフト表（印刷/PDF/ソート/ドラッグ）、分析レポート、休み希望の承認、本部管理、PIN設定

【トーン】「〜します」「〜を押します」の丁寧な手順書。専門用語には必ず補足。
【出力】章ごとの見出し＋手順（番号付き）＋スクショ挿入位置＋注意ボックス。
```
