## 1. サービス紹介リーフレット（営業用A4 PDF）

```
あなたはプロのマーケティングデザイナーです。
以下の情報をもとに、飲食店・小売店・医療施設向けのSaaSサービス「ラクシフトAI」の営業用リーフレット（A4両面）のコピーを作成してください。

【キャッチコピー】シフト作成を、AIに任せよう。
【サブコピー】数理最適化AIが労基法を守り、人件費を抑えながら最適なシフトを瞬時に自動生成

【対応業種】
- 飲食店（カフェ、レストラン、居酒屋）
- 小売店（コンビニ、アパレル、ドラッグストア）

- 全プラン共通: 初期費用0円、AI自動生成、労基法チェック、ガントチャート、休み希望管理、人件費分析

【主な機能】
- AIシフト自動生成（数理最適化エンジン搭載）
- イレギュラーシフト（人員不足警告）の視覚化
- スタッフ優先度・契約区分による配置最適化

Step 3: スタッフ情報を登録

【トーン】専門的すぎず、店長・オーナーが読んで「使ってみたい」と思える親しみやすい文体。
【出力形式】A4両面のテキスト原稿（表面: キャッチ＋特長＋業種、裏面: 料金＋導入の流れ＋FAQ）
```

## 2. 操作マニュアル（導入後のお客様向け）

```
あなたはSaaSの操作マニュアルを作成するテクニカルライターです。
以下の情報をもとに、「ラクシフトAI」の操作マニュアルを作成してください。
対象読者は飲食店や小売店の店長・マネージャーで、ITリテラシーは高くありません。
スクリーンショットの代わりに、操作手順を具体的に記述してください。

【サービス概要】
ラクシフトAIは、労働基準法を遵守しつつ、店舗の必要人数とスタッフの希望、そして「人件費」を両立させたシフトを自動生成するクラウドサービスです。

【ログイン方法】
1. 店舗ログイン: 発行された契約IDとパスワードでログイン
2. 管理者ログイン: 店舗画面から管理者ID「admin」でログイン（全機能が利用可能）

【画面構成】
- ダッシュボード: 今日の出勤人数、営業時間、シフト詳細、クイックメニュー
- シフト表: ガントチャート（ドラッグ&ドロップで直感的に時間・担当者変更可能） / カレンダー / リスト / テーブルの4表示
- 申請リスト: スタッフからの休み希望を一覧表示（承認/却下）
- 分析・レポート: 月間推定人件費、日次コスト推移グラフ、スタッフ別労働時間・支給額目安
- スタッフ管理: スタッフの追加・編集・削除、優先度・契約区分の設定
- 店舗設定: 営業時間、定休日、シフトパターン、人員配置、休憩ルール

【AIアルゴリズムの仕組み（店長向け解説）】
ラクシフトAIは、単純な予測ではなく「数理最適化技術」を用いています。
1. 絶対に守るルール（ハード制約）: 労働基準法（1日8時間・週40時間、休憩時間、週1日の休日）や、スタッフの「NG日（休み希望）」は100%厳守します。
2. 調整するルール（ソフト制約）: 「店舗が求める必要人数」と「スタッフの優先度・契約区分」「人件費の最小化」を天秤にかけ、最も両者が納得する理想的なパズルを解きます。
3. 緊急対応（フェイルセーフ）: 繁忙期などでどうしても人が足りない場合、AIはエラーで停止せず、「希望時間に合わないが、やむを得ず配置したシフト」を生成して店長にアラートを出します。

【AIシフト作成とイレギュラー表示の手順】
1. 画面右上の「AIシフト作成」ボタンをクリック
2. 作成範囲（空きシフトのみ埋める / 月間を作成 / リセットして再構築）を選択
3. 「作成を実行」をクリック → AIが最適化を計算（10〜30秒）
4. プレビュー画面が表示されます。
   - 【重要】赤斜線の太枠になっているシフトは「イレギュラーシフト」です。アルゴリズムが人員不足を検知し、やむを得ず条件を緩和して配置した箇所です。必ず店長が目視で確認し、手動で変更してください。
5. 内容を確認して「確定して保存」をクリック。

【スタッフ設定の重要機能】
1. 契約区分の設定
   - 「レギュラー」「一般」「スポット」から選択します。
   - 「レギュラー」は優先的にシフトに配置され、「スポット」は人手が足りない時の穴埋めとして後回しにされます。
2. シフト優先度の設定
   - 「高」「中」「低」から選択します。特定の人を確実にシフトに入れたい場合は「高」に設定します。
3. 勤務条件の設定
   - 「1日の最大労働時間」「週の最大出勤日数」に加えて、「週の最低出勤日数」を設定可能。「シフトに入れず稼げない」という不満を防ぎます。

【休み希望の管理】
- スタッフが自身のスマホから休み希望を提出 → 管理者が「申請リスト」で承認。承認された日はAIが自動的に配置から除外します。

【出力形式】章立てされたマニュアル文書。見出し・箇条書き・注意事項を使い、読みやすく構成。
【トーン】丁寧語。専門用語は避け、「〜してください」「〜が表示されます」のような指示形式。
```

## 4. 投資家/パートナー向けピッチ資料

```
あなたはスタートアップのピッチ資料を作成するコンサルタントです。
「ラクシフトAI」の事業概要をまとめたピッチデック用テキストを作成してください。

【会社】〇〇株式会社（※自社名を入力）
【サービス】ラクシフトAI - AIシフト自動生成SaaS
【フェーズ】商用リリース済み、テナントオンボーディング開始、Stripe自動課金連携済み

【技術スタック】
- フロントエンド: HTML/JS + Tailwind CSS（Cloudflare Pages配信 / Vanilla JS 7000行超のSPA）
- バックエンド: Python FastAPI + PuLP（MILP最適化エンジン）+ Gemini（LLM監査）
- データベース: Supabase（PostgreSQL + RLSベースの独自セッション認証 + RPC）
- 決済: Stripe（Webhook連動テナント自動プロビジョニング）

【競合優位性（AIアルゴリズムと堅牢性）】
1. MILP (混合整数線形計画問題) エンジン
   - 単なるLLM生成ではなく、PuLPを用いた厳密な数理最適化。労働基準法を「絶対制約（Hard Constraints）」として数式化し、違反を100%防止。
2. コスト最適化関数（Cost Minimization）
   - 「人件費（時給×時間）の最小化」と「スタッフ評価ランク・シフト優先度・契約区分」を一つのペナルティ関数に統合。現場のコスト感覚に合致したシフトを生成。
3. 人員不足への自動対応（Greedy Fallback）
   - どうしてもシフトが埋まらない場合、計算不能(Infeasible)で停止せず、「イレギュラーシフト（is_irregular）」フラグを立てて強制的に配置し、UI上で赤斜線としてマネージャーに警告を出す実践的フェイルセーフを実装。
4. エンタープライズ級のセキュリティ
   - SupabaseのRow Level Security (RLS) と独自セッションID発行ロジックを組み合わせ、テナント間のデータ漏洩を完全に遮断。Stripeと連携したサブスクリプション状態の自動監視機能も搭載。

【出力形式】各スライドのタイトル + 箇条書き内容 + スピーカーノート
```

## 6. AIアルゴリズム技術資料（エンジニア・アライアンス向け）

```
あなたはAIソリューションアーキテクトです。
以下のアルゴリズム詳細をもとに、「ラクシフトAI」のコアエンジン技術仕様書（ホワイトペーパー）の構成と原稿を作成してください。

【エンジン概要】
- フレームワーク: PuLP (Python) + CBC Solver
- 方式: 混合整数線形計画問題 (MILP) によるスケジューリング + Geminiによる生成結果監査
- 処理フロー:
  1. 需要パターンの時間粒度へのマッピング (15分単位の要件分解)
  2. スタッフ条件（優先度・契約区分・役職・スキル・希望時間・NG日）のフロントエンドからのタグ解析
  3. 制約式の定義（ハード制約・ソフト制約）
  4. 目的関数（ペナルティ＆コスト最小化）の設定と最適化計算 (3 Tier フォールバック方式)

【ハード制約（絶対厳守）】
- 労働基準法第32条: 1日8時間、週40時間を超えない（月間目安176時間以内への収束）
- 労働基準法第34条: 実働6時間「以上」で45分、8時間「以上」で60分の休憩付与（境界値の厳格化）
- 労働基準法第35条: 連続勤務を6日以内（週1日の休日）に制限
- インターバル規制: 退勤から翌日の出勤まで最低10時間を確保
- NG日・承認済みの休みの確実な除外

【ソフト制約・コスト関数（ペナルティによる最適化）】
- 優先度タグ (`priority:high/medium/low`): 最優先スタッフには -50,000 のボーナス、穴埋め要員には +20,000 のペナルティを付与。
- 契約区分タグ (`contract:regular/spot`): レギュラーには -10,000、スポットには +5,000 のコストを付与し配置比率を調整。
- 人件費の最小化: 時給×労働時間をベースコストとし、月給スタッフは変動費ゼロとして扱うことで、総人件費を抑える配置を実現。
- スタッフの「週の最低出勤日数」に基づく需要按分（公平性担保）。

【実践的フェイルセーフ（Infeasible回避）】
- 3 Tier Fallback: Tier3(完全制約) → Tier2(バランス緩和) → Tier1(労基法のみ) の順で探索を緩和。
- それでも絶望的に人が足りない場合は Greedy Fallback へ移行。不足スロットを特定し、AIが「イレギュラーシフト（is_irregular = True）」として強制的にスタッフを割り当てる。
- フロントエンド側でイレギュラーフラグを検知し、赤色斜線の太枠（UI警告）として描画することで、管理者に人的な判断・修正を促す「ヒューマン・イン・ザ・ループ」を実現。
- UI側でドラッグ&ドロップによる手動修正を行った際は、バックエンドと同一の休憩計算ロジック（`>=` 判定）が即座に走り、労基法違反を防止する。

【トーン】技術的で説得力のある論理的な文体。アルゴリズムがいかに「現場の実態（人員不足など）」に強く、かつ「法律」を厳守する安全なシステムであるかを強調。
【出力形式】Markdown形式のホワイトペーパー
```
