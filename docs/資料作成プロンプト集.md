以下の情報をもとに、飲食店・小売店・医療施設向けのSaaSサービス「ラクシフトAI」の営業用リーフレット（A4両面）のコピーを作成してください。

【サービス名】ラクシフトAI
【キャッチコピー】シフト作成を、AIに任せよう。
【サブコピー】数理最適化AI × Gemini AIで、労基法を守りながら最適なシフトを瞬時に自動生成

【3つの特長】
1. AIが自動生成：PuLP数理最適化エンジンが労働基準法（32条/34条/35条）を遵守しながら、最適な人員配置を自動計算。さらにGemini AIが最終監査を実施。
2. プレビューで安心：生成結果を保存前にプレビュー画面で確認可能。統計サマリー（配置人数・労働時間・対象日数）と日別シフト一覧を表示。不安なら「キャンセル」でやり直しOK。
3. 業種別テンプレート：飲食店（早番/中番/遅番/ランチ/ディナー）、小売店、オフィス、医療・介護の4種類のプリセットをワンクリック適用。初回設定が30秒で完了。

【対応業種】
- 飲食店（カフェ、レストラン、居酒屋）
- 小売店（コンビニ、アパレル、ドラッグストア）

【料金プラン】

- Pro: 月額4,480円（税別）/ スタッフ50名まで
- Premium: 月額9,980円（税別）/ スタッフ無制限
- 全プラン共通: 初期費用0円、AI自動生成、労基法チェック、ガントチャート、休み希望管理

【主な機能】
- AIシフト自動生成（数理最適化＋Gemini AI監査）
- シフト生成プレビュー機能
- ガントチャート（ドラッグ&ドロップ対応）
- カレンダー/リスト/テーブルの3ビュー
- 休み希望管理（申請→承認フロー、AI生成時に自動除外）
- スタッフ管理（役職・評価・勤務条件）
- 店舗設定（営業時間・定休日・シフトパターン・人員配置）
- AI診断レポート（労基法違反リスク検出）
- Stripe決済（クレジットカード）
- お知らせ機能
- シフト印刷機能
- パスワード変更機能

【導入の流れ】
Step 1: Webからお申込み（3分）
Step 2: カード決済完了→即日利用開始
Step 3: スタッフ情報を登録
Step 4: 「AIシフト作成」ボタン→自動生成→プレビュー→保存

【労基法自動準拠】
- 第32条: 1日8時間・週40時間以内
- 第34条: 6時間超→45分、8時間超→60分の休憩
- 第35条: 週1日以上の休日（連続6日まで）

【差別化ポイント】

- 3段階フォールバック（制約緩和→貪欲法）で必ず結果を返す
- マスターパスワードで運営サポートが即座に対応可能

【トーン】専門的すぎず、店長・オーナーが読んで「使ってみたい」と思える親しみやすい文体。
【出力形式】A4両面のテキスト原稿（表面: キャッチ＋特長＋業種、裏面: 料金＋導入の流れ＋FAQ）

## 2. 操作マニュアル（導入後のお客様向け）

```
あなたはSaaSの操作マニュアルを作成するテクニカルライターです。
以下の情報をもとに、「ラクシフトAI」の操作マニュアルを作成してください。
対象読者は飲食店や小売店の店長・マネージャーで、ITリテラシーは高くありません。
スクリーンショットの代わりに、操作手順を具体的に記述してください。

【サービス概要】
ラクシフトAIは、AIがシフトを自動生成するクラウドサービスです。
ブラウザからアクセスし、ログインして使用します。

【ログイン方法】
1. 店舗ログイン
   - URL: https://rakushift-ai.pages.dev
   - 契約IDとパスワードを入力してログイン
   - 初期パスワード: rakushift1234
2. 管理者ログイン
   - 店舗ログイン後、管理者ID「admin」とパスワードでログイン
   - 管理者モードではAIシフト作成・スタッフ管理・設定変更が可能

【画面構成】
- ダッシュボード: 今日の出勤人数、営業時間、シフト詳細
- シフト表: ガントチャート/カレンダー/リスト/テーブルの4表示
- 申請リスト: スタッフからの休み希望を一覧表示（承認/却下）
- 分析・レポート: 月間統計、AI診断レポート
- スタッフ管理: スタッフの追加・編集・削除
- 店舗設定: 営業時間、定休日、シフトパターン、人員配置、休憩ルール
- マニュアル: アプリ内の操作ガイド

【AIシフト作成の手順】
1. 画面右上の「AIシフト作成」ボタンをクリック
2. 作成範囲を選択:
   - 「今月の空きシフトのみ埋める」: 既存シフトはそのまま、空きだけ埋める
   - 「来週分を作成」: 来週1週間分を作成
   - 「現在のシフトをリセットして再構築」: 全て作り直す
3. 「作成を実行」をクリック → AIが最適化を計算（10-30秒）
4. プレビュー画面が表示される:
   - 上部: 生成シフト数、対象日数、配置スタッフ数、合計労働時間
   - 下部: 日付ごとのシフト一覧（スタッフ名、出勤/退勤時間、休憩、実働時間）
5. 内容を確認して:
   - 「確定して保存」→ シフトがカレンダーに反映
   - 「キャンセル」→ 破棄してやり直し

【シフトパターンの設定】
1. 店舗設定 → シフトパターン(早番/遅番など)セクション
2. 「追加」ボタンで手動追加、またはプリセットから一括追加:
   - 飲食店向け（早番/中番/遅番/通し/ランチ/ディナー）
   - オフィス向け（日勤/早番/遅番/半日AM/半日PM）
   - 小売店向け（早番/遅番/通し/午前/午後/夕方）
   - 医療・介護向け（日勤/早番/遅番/夜勤/準夜勤/半日）

【パスワード変更】
1. 店舗設定 → システム設定セクション
2. 「店舗ログインパスワードを変更」ボタンをクリック
3. 現在のパスワード、新しいパスワード（6文字以上）、確認を入力
4. 「変更する」をクリック
※ パスワードを忘れた場合は運営にお問い合わせください（マスターパスワードで対応）

【休み希望の管理】
1. スタッフがログインして休み希望を提出（日付を複数選択→理由入力→送信）
2. 管理者が「申請リスト」で一覧確認
3. 「承認」or「却下」ボタンで処理
4. 承認された日は、AIシフト生成時に自動的に配置除外

【出力形式】章立てされたマニュアル文書。見出し・箇条書き・注意事項を使い、読みやすく構成。
【トーン】丁寧語。専門用語は避け、「〜してください」「〜が表示されます」のような指示形式。
```
