# ラクシフトAI お客様向け資料 制作計画

> 最終更新: 2026年5月11日

---

## 1. 資料の目的

ラクシフトAIを導入検討中のお客様、および導入済みのお客様向けに、サービスの価値・使い方・料金を分かりやすく伝える資料群を制作する。

---

## 2. 制作する資料一覧

### 📄 資料A: サービス紹介リーフレット（営業用）

**目的:** 初回商談・展示会・DM送付用

**構成:**
1. キャッチコピー: 「シフト作成、AIに任せませんか？」
2. 3つの特長
   - 🤖 AIが労基法を守りながら最適シフトを自動生成
   - 👀 プレビュー機能で確認してから保存（安心設計）
   - 🚨  personnel shortage alert (イレギュラーシフト赤枠警告)
   - 💰 月額3,380円〜、初期費用0円
3. 対応業種: 飲食店 / 小売店 / オフィス / 医療・介護
4. プリセット対応: 業種別テンプレートをワンクリック適用
5. 柔軟なスタッフ設定: 希望時間の考慮トグル、週の最低出勤日数
5. 料金表
6. 導入の流れ（4ステップ）
7. QRコード（申込ページへ）

**形式:** A4両面 / PDF

---

### 📄 資料B: 操作マニュアル（導入後）

**目的:** 導入済みのお客様への操作ガイド

**構成:**
1. ログイン方法（店舗ログイン / 管理者ログイン）
2. ダッシュボードの見方
3. スタッフ登録・編集
4. 店舗設定
   - 営業時間、定休日
   - **シフトパターン設定**（プリセット一括適用の説明）
   - 人員配置要件
   - 休憩ルール
5. AIシフト作成
   - 作成範囲の選択（空きシフト / 来週 / 全リセット）
   - **プレビュー画面の見方**（統計サマリー / 日別一覧 / **赤枠のアラート確認**）
   - 「確定して保存」の操作
6. シフト表の操作（見やすい新ガントチャート、手動編集）
7. 休み希望の管理（申請→承認フロー）
8. AI診断レポートの活用
9. **パスワード変更方法**
10. プラン変更・支払い方法
11. よくある質問（FAQ）

**形式:** PDF / アプリ内マニュアル（既にindex.html内に実装済み）

---

## 4. 訴求ポイント（差別化要素）

1. **プレビュー機能** — 生成結果を確認してから保存（競合にない安心設計）
2. **実践的フェイルセーフ** — 人員不足時でもエラー停止せず、イレギュラーシフトを赤枠で警告表示し店長判断を仰ぐ
3. **柔軟なスタッフ設定** — 最低出勤日数保証や、社員/バイトの希望時間考慮トグル
4. **業種別プリセット** — 初回設定が30秒で完了
5. **労基法自動準拠** — AIが法律を守るので安心
6. **マスターパスワード** — 店舗がPWを忘れても運営が対応可能
7. **月額3,380円〜** — 小規模店舗でも導入しやすい価格設計
