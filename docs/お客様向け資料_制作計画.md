# ラクシフトAI お客様向け資料 制作計画

**作成日:** 2026年3月31日

---

## 必要な資料の全体像

お客様向けには、**営業フェーズ** と **導入後フェーズ** で異なる資料が必要です。

```
【営業フェーズ】                    【導入後フェーズ】

A. サービス紹介資料（営業用）        D. 管理者マニュアル
B. 料金プラン表                    E. スタッフ向けガイド
C. セキュリティシート               F. よくある質問（FAQ）
```

---

## A. サービス紹介資料（営業用スライド）

**用途：** 商談・プレゼン・メール送付
**形式：** PDF（横型スライド形式） 10〜15ページ
**対象：** 店舗オーナー・経営者・店長

### 構成案

| ページ | 内容 | ポイント |
|---|---|---|
| 1 | 表紙 | サービス名・キャッチコピー・ロゴ |
| 2 | こんなお悩みありませんか？ | シフト作成の課題3〜4つを提示 |
| 3 | ラクシフトAIとは | サービス概要を1文で。全体イメージ図 |
| 4 | 3つの特長 | (1) AI自動生成 (2) 希望の自動反映 (3) 人件費の見える化 |
| 5 | 機能紹介：AI自動生成 | ビフォーアフター（手作業3時間 → AI数分） |
| 6 | 機能紹介：シフト表 | 画面キャプチャ（テーブル表示・カレンダー表示） |
| 7 | 機能紹介：スタッフ管理・申請 | 希望休提出 → 承認 → 自動反映の流れ |
| 8 | 機能紹介：分析・レポート | 人件費グラフの画面キャプチャ |
| 9 | セキュリティ | データ暗号化・テナント分離・HTTPS等を簡潔に |
| 10 | 導入ステップ | 4ステップ図（アカウント作成→設定→登録→運用開始） |
| 11 | 料金プラン | プラン比較表（別紙に詳細） |
| 12 | 導入事例・お客様の声 | ※実績ができ次第追加 |
| 13 | よくある質問 | 3〜5問を厳選 |
| 14 | お問い合わせ | 連絡先・無料トライアルへの導線 |

### 制作に必要なもの

- [ ] サービスロゴ（正式版）
- [ ] 画面キャプチャ（デモ環境のスクリーンショット）
- [ ] キャッチコピーの確定
- [ ] 料金プランの確定
- [ ] デザインテンプレート（Canva / Figma / PowerPoint）
- [ ] 導入事例（β版利用者へのヒアリング等）

### 制作方法の選択肢

| 方法 | コスト | クオリティ | 納期目安 |
|---|---|---|---|
| Canva（自作） | 無料〜月1,500円 | 中 | 1〜2日 |
| PowerPoint / Googleスライド（自作） | 無料 | 中 | 1〜2日 |
| Figma（自作） | 無料 | 高 | 2〜3日 |
| デザイナー外注（ココナラ等） | 3〜10万円 | 高 | 1〜2週間 |
| デザイン会社 | 15〜50万円 | 非常に高 | 2〜4週間 |

## B. 料金プラン表

**用途：** 商談時の価格説明・Webサイト掲載
**形式：** PDF 1ページ or Webページ
**対象：** 意思決定者（オーナー・経営者）

### 構成案

```
┌──────────────┬──────────────┬──────────────┐
│   フリー      │  スタンダード  │  プレミアム    │
│   ¥0/月      │  ¥X,XXX/月   │  ¥XX,XXX/月  │
├──────────────┼──────────────┼──────────────┤
│ スタッフ5名   │ スタッフ30名  │ スタッフ無制限 │
│ AI生成 月3回  │ AI生成 無制限 │ AI生成 無制限  │
│ 基本機能      │ 全機能       │ 全機能        │
│ -            │ 分析・レポート │ 分析・レポート │
│ -            │ PDF出力      │ PDF出力       │
│ -            │ -            │ 優先サポート   │
│ -            │ -            │ API連携       │
└──────────────┴──────────────┴──────────────┘
        ※ 料金は要確定
```

### 決めるべきこと

- [ ] 各プランの月額料金
- [ ] プラン間の機能差
- [ ] 無料トライアル期間（14日 or 30日）
- [ ] 年間契約の割引率
- [ ] AI APIの利用料の負担方法（込み or ユーザー負担）

## C. セキュリティシート

**用途：** 企業・チェーン店との商談時の信頼獲得
**形式：** PDF 2〜3ページ
**対象：** IT部門・情報セキュリティ担当者

### 構成案

| セクション | 記載内容 |
|---|---|
| データ保護 | 暗号化方式（AES-256 at rest, TLS 1.2+ in transit）、パスワードのbcryptハッシュ |
| アクセス制御 | 2段階ログイン、役職別権限、Row Level Security |
| インフラ | クラウド基盤（Supabase / GCP）の認証・準拠規格 |
| データ分離 | マルチテナントアーキテクチャ、テナント間の完全分離 |
| AI利用 | APIキーのサーバーサイド管理、送信データの範囲 |
| データ保持 | バックアップポリシー、データ削除対応 |
| 障害対応 | 可用性目標、監視体制 |

### 決めるべきこと

- [ ] SLA（稼働率保証）の数値
- [ ] バックアップ頻度・保持期間
- [ ] インシデント対応フロー
- [ ] 個人情報保護方針（プライバシーポリシー）
- [ ] 利用規約

## D. 管理者マニュアル

**用途：** 導入後の店舗管理者向け操作ガイド
**形式：** PDF or Webページ（ヘルプセンター） 30〜50ページ相当
**対象：** 店長・マネージャー

### 構成案

| 章 | 内容 |
|---|---|
| 1. はじめに | サービス概要、推奨環境、ログイン方法 |
| 2. 初期設定 | 営業時間・定休日・人数ルール・休憩ルール・役職の設定 |
| 3. スタッフ登録 | スタッフの追加・編集・削除・評価設定 |
| 4. シフト作成（手動） | シフトの追加・編集・削除の操作手順 |
| 5. シフト作成（AI自動） | 自動生成の実行手順・対象期間の選択・強制モードの説明 |
| 6. 申請管理 | 希望休・出勤希望の確認・承認・却下の操作手順 |
| 7. 分析・レポート | 人件費グラフの見方・PDF出力方法 |
| 8. ダッシュボード | 各指標の見方・クイックアクション |
| 9. AI設定 | APIキーの設定・モデル選択 |
| 10. トラブルシューティング | よくある問題と対処法 |

### 各ページの構成

```
┌─────────────────────────────────┐
│ 5. シフト作成（AI自動生成）       │
│                                 │
│ ■ 概要                          │
│   自動生成機能の説明（2〜3行）     │
│                                 │
│ ■ 操作手順                       │
│   1. サイドバーから「シフト表」    │
│   2. 「自動作成」ボタンをクリック  │
│   3. 対象期間を選択              │
│   4. 「生成開始」をクリック       │
│   [画面キャプチャ]               │
│                                 │
│ ■ 注意点                        │
│   ・人員不足時は〜               │
│   ・強制モードとは〜             │
│                                 │
│ ■ 関連項目                       │
│   → 2. 初期設定 / 6. 申請管理    │
└─────────────────────────────────┘
```

### 制作方法の選択肢

| 方法 | 特徴 |
|---|---|
| Notion | 手軽に作成・更新可能。リンク共有 |
| GitBook | 技術ドキュメント向き。バージョン管理可能 |
| Googleドキュメント → PDF | シンプル。印刷配布にも対応 |
| 自社ヘルプセンター（Webページ） | 検索性が高い。長期的にはこれが理想 |

## E. スタッフ向けかんたんガイド

**用途：** 一般スタッフへの配布用（店内掲示 or LINE送付）
**形式：** PDF 1〜2ページ（A4両面印刷想定）
**対象：** アルバイト・パートスタッフ

### 構成案（A4表面）

```
┌─────────────────────────────────────────┐
│     ラクシフトAI スタッフ向けガイド       │
│                                         │
│  ■ ログイン方法                          │
│    1. ブラウザでURLにアクセス             │
│    2. 契約IDと店舗パスワードを入力        │
│    3. 「ログイン」をタップ               │
│    [QRコード] ← アクセスURL              │
│                                         │
│  ■ シフトの確認方法                      │
│    ・ダッシュボード → 本日のシフト        │
│    ・シフト表 → カレンダーで月間確認      │
│    [画面キャプチャ]                      │
│                                         │
│  ■ 希望休の出し方                        │
│    1. 「申請管理」をタップ               │
│    2. 「新規申請」→「希望休」を選択      │
│    3. 日付と理由を入力                   │
│    4. 「提出」をタップ                   │
│    [画面キャプチャ]                      │
│                                         │
│  ※ 困ったときは店長に相談してください     │
└─────────────────────────────────────────┘
```

### ポイント

- **文字は大きく、手順は3〜4ステップ以内**
- **画面キャプチャを多用**（文章より画像で伝える）
- **QRコード掲載**（URLを手入力させない）
- **印刷して店内掲示** or **LINEでPDF送付** を想定

## F. よくある質問（FAQ）

**用途：** Webサイト掲載・営業資料の補足
**形式：** Webページ or PDF 2〜3ページ
**対象：** 全ユーザー

### 想定Q&A

**導入前（営業向け）**

| Q | A |
|---|---|
| 導入にどのくらい時間がかかりますか？ | 最短30分で初回シフト生成まで可能です |
| パソコンが苦手でも使えますか？ | はい。直感的な操作で、特別なITスキルは不要です |
| スマホから使えますか？ | はい。ブラウザから利用可能です |
| 無料で試せますか？ | はい。無料トライアルをご用意しています |
| 他のシフト管理ツールからの移行は？ | スタッフ情報の登録のみで開始できます |
| 複数店舗で使えますか？ | はい。店舗ごとに独立した環境を提供します |

**導入後（運用向け）**

| Q | A |
|---|---|
| AIが作ったシフトを手動で修正できますか？ | はい。自動生成後に自由に編集できます |
| 希望休を出し忘れた場合は？ | 管理者が手動でシフトを調整できます |
| スタッフが足りない場合はどうなりますか？ | 不足を通知し、強制モードで最大限カバーします |
| データのバックアップは？ | クラウド上で自動バックアップされます |
| 解約したらデータはどうなりますか？ | 解約後30日間は保持し、以降完全削除します |

## 制作の優先順位

クライアントへの提案・導入を見据えた優先順位です。

```
【最優先】すぐに必要
━━━━━━━━━━━━━━━━━
 A. サービス紹介資料    ← 営業活動に必須
 B. 料金プラン表       ← 商談のクロージングに必須

【高】導入決定〜初期に必要
━━━━━━━━━━━━━━━━━
 E. スタッフ向けガイド   ← 導入初日に配布
 D. 管理者マニュアル    ← 管理者の自走に必要

【中】信頼構築・長期運用
━━━━━━━━━━━━━━━━━
 C. セキュリティシート   ← 企業・チェーン店向け商談時
 F. FAQ               ← Webサイト・問い合わせ削減
```

## まとめ

| 資料 | 形式 | ページ数 | 主な用途 |
|---|---|---|---|
| A. サービス紹介資料 | 横型PDF（スライド） | 10〜15P | 商談・メール送付 |
| B. 料金プラン表 | PDF / Web | 1P | 価格説明 |
| C. セキュリティシート | PDF | 2〜3P | 企業向け信頼構築 |
| D. 管理者マニュアル | PDF / Web | 30〜50P | 導入後の操作ガイド |
| E. スタッフ向けガイド | A4 PDF | 1〜2P | 店内掲示・LINE配布 |
| F. FAQ | Web / PDF | 2〜3P | 問い合わせ削減 |

営業フェーズでまず **A（サービス紹介資料）** と **B（料金プラン）** を作成し、導入が決まったら **D（管理者マニュアル）** と **E（スタッフガイド）** を用意する流れが効率的です。
