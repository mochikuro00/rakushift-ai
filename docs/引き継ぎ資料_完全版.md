## 1. サービス概要

**ラクシフトAI** は、飲食・小売・医療介護店舗向けのAIシフト自動生成SaaS。

- **Python数理最適化(PuLP/MILP)** でベースシフトを生成（3段階フォールバック）
- **Gemini AI** が労働基準法チェック・最終監査
- **プレビュー機能** で生成結果を確認してから保存
- マルチテナント対応（1契約ID = 1店舗）
- Stripe決済によるサブスクリプション課金

**URL:**
- 本体: https://rakushift-ai.pages.dev
- 管理画面: https://rakushift-ai.pages.dev/admin
- GitHub: https://github.com/mochikuro00/rakushift-ai

## 10. AIシフト生成の仕組み

### フロー（プレビュー対応版）
```
「AIシフト作成」ボタン → 作成範囲選択
  ↓
1. /check — 人員充足チェック
  ↓
2. /generate — PuLP MILP最適化 → Gemini AI監査
  ↓
3. ★プレビューモーダル表示（統計サマリー＋日別シフト表）
  ↓
4. ユーザーが「確定して保存」→ DB保存
  ↓
5. AI診断（バックグラウンド実行）
```

### 制約（3段階フォールバック）

**Tier 1: 法定（絶対遵守）**
- 1日8時間以内 / 週40時間以内（労基法32条）
- 6h超→45分休憩、8h超→60分休憩（労基法34条）
- 連続6日まで、週1日休日（労基法35条）

**Tier 2: 店舗ルール**
- 最低人員、管理者常駐、定休日

**Tier 3: 最適化**
- チーム戦力バランス、新人メンター、コスト最小化

**解けない場合:** Tier3緩和 → Tier2緩和 → 貪欲法フォールバック

## 11. Stripe決済フロー

```
申込フォーム → /stripe/new-subscription → Stripe決済
  ↓ Webhook (checkout.session.completed)
テナント自動作成 → config更新
  ↓ 運営が管理画面で確認
「案内送信」→ ウェルカムメール（契約ID・パスワード）
```

### 決済失敗時
1. `invoice.payment_failed` → `past_due` 状態
2. 顧客画面にオレンジバナー + 再決済ボタン
3. 21日間未対応 → 自動ライセンス停止
