## 1. 本部アカウントについて

本部アカウントは、複数の店舗（テナント）を横断的に**閲覧・管理**するための統括管理者向けアカウントです。

### 権限の範囲

| 機能 | 本部管理者 | 店舗管理者 |
|------|:---:|:---:|
| 店舗一覧の閲覧 | ✅ | ❌ |
| 任意の店舗へのアクセス | ✅ (※) | 自店舗のみ |
| シフト表の閲覧 | ✅ | ✅ |
| スタッフ情報の閲覧 | ✅ | ✅ |
| 分析・レポートの閲覧 | ✅ | ✅ |
| シフト作成・編集 | ❌ | ✅ |
| スタッフの追加・削除 | ❌ | ✅ |
| 店舗設定の変更 | ❌ | ✅ |

> **※** 店舗へのアクセスには、その店舗の**契約ID**と**管理者パスワード**が必要です。

### セキュリティ方針

- 本部管理者は**閲覧専用**です。店舗のデータを変更することはできません。
- 各店舗へのアクセスには、必ず**契約IDとパスワード**の入力が必要です。
- 一覧表から直接店舗に入ることはできません（情報漏洩防止のため）。

## 2. ログイン方法

### ステップ 1: ログイン画面にアクセス

ブラウザで以下のURLにアクセスしてください。

```
https://rakushift-ai.pages.dev/
```

### ステップ 2: 「本部・統括」タブを選択

ログインモーダルが表示されたら、上部のタブから **「本部・統括」** を選択します。

### ステップ 3: 認証情報を入力

| 項目 | 入力内容 |
|------|---------|
| **本部ID** | 発行された本部管理者ID |
| **パスワード** | 本部管理者パスワード |

### ステップ 4: ログインボタンを押下

「ログイン」ボタンを押すと、本部ダッシュボードが表示されます。

> ⚠️ **パスワードを5回連続で間違えると、一定時間ロックアウトされます。**

## 3. 本部ダッシュボードの見方

ログイン直後に表示される画面です。

### ① ヘッダーバー

画面上部に以下のコントロールが表示されます：

- **閲覧専用モード** バッジ — 現在のモードを示します
- **店舗一覧** ボタン — ダッシュボードに戻ります（店舗閲覧中）
- **ログアウト** ボタン — 本部からログアウトします

### ② 店舗アクセスカード（入力フォーム）

店舗に入るための認証フォームです。

| フィールド | 説明 |
|-----------|------|
| **契約ID** | 店舗に発行された15桁の契約ID |
| **パスワード** | 店舗の管理者パスワード、または店舗用パスワード |

### ③ 登録店舗一覧テーブル

全テナント店舗の一覧が表示されます。**情報の閲覧のみ**で、ここから直接店舗に入ることはできません。

| 列 | 内容 |
|---|------|
| **店舗名** | 登録されている店舗名と担当者名 |
| **契約ID** | 店舗固有のID（15桁） |
| **プラン** | 契約プラン（Standard / Pro / Premium / OEM / 未契約） |
| **スタッフ** | 登録スタッフ数 |
| **状態** | 稼働中 / 停止 |
| **登録日** | テナント登録日 |

## 4. 店舗への閲覧アクセス

### 手順

1. 本部ダッシュボードの **「指定の店舗を閲覧」** カードを見つけます
2. **契約ID** を入力します（店舗一覧テーブルで確認可能）
3. **パスワード** を入力します（店舗管理者から取得してください）
4. **「閲覧する」** ボタンをクリックします

### 認証成功時

- トースト通知「店舗情報を読み込みました（閲覧専用モード）」が表示されます
- 店舗のダッシュボードに自動遷移します
- サイドバーメニューが有効になり、各画面にアクセスできます

### 認証失敗時

- トースト通知「IDまたはパスワードが正しくありません」が表示されます
- 契約IDとパスワードを再確認してください

> 💡 **ヒント**: 店舗管理者パスワードだけでなく、店舗用パスワード（スタッフ用）でもアクセス可能です。

## 5. 閲覧専用モードでの操作

店舗にアクセスすると、以下の画面が**閲覧専用**で利用できます。

### アクセス可能な画面

| 画面 | できること |
|------|-----------|
| **ダッシュボード** | 今日のシフト詳細、出勤状況、人件費グラフの確認 |
| **シフト表** | 月間・週間シフト表の閲覧、印刷 |
| **お知らせ** | プラットフォームからのお知らせ確認 |
| **申請リスト** | スタッフからの休み希望・申請一覧の閲覧 |
| **分析・レポート** | 人件費分析、AI診断結果の閲覧 |
| **スタッフ管理** | 登録スタッフ一覧の閲覧 |
| **店舗設定** | 営業時間・役職設定の閲覧 |
| **マニュアル** | 操作ガイドの閲覧 |

### 制限事項（閲覧専用モード）

以下の操作は**実行できません**：

- ❌ シフトの作成・編集・削除
- ❌ スタッフの追加・編集・削除
- ❌ 申請の承認・却下
- ❌ 店舗設定の変更
- ❌ AIシフト作成の実行

> 編集が必要な場合は、各店舗の管理者に直接ログインしてもらうか、店舗管理者アカウントで個別にログインしてください。

### 別の店舗に切り替える

1. ヘッダー右上の **「店舗一覧」** ボタンをクリック
2. 本部ダッシュボードに戻ります
3. 別の店舗の契約ID + パスワードを入力してアクセス

## 6. ログアウト

以下のいずれかの方法でログアウトできます：

1. **ヘッダー右上** の「ログアウト」ボタン
2. **本部ダッシュボード** のヘッダー内「ログアウト」ボタン

ログアウトすると即座にログイン画面に戻ります。

## 7. よくある質問 (FAQ)

### Q: 本部IDとパスワードはどこで取得できますか？

**A**: プラットフォーム運営管理者（admin）から発行されます。初期アカウントは以下の通りです：

| ID | パスワード | 用途 |
|---|---|---|
| `hq_master` | (運営から通知) | マスターアカウント |

### Q: 店舗の契約IDがわからない場合は？

**A**: 本部ダッシュボードの「登録店舗一覧」テーブルに表示されています。パスワードは各店舗管理者にお問い合わせください。

### Q: 閲覧専用モードで編集操作が必要になった場合は？

**A**: 本部アカウントでは編集はできません。該当店舗の管理者アカウント（契約ID + 管理者パスワード）で「店舗管理者」タブからログインしてください。

### Q: 複数の店舗を同時に開けますか？

**A**: 1つのブラウザタブでは同時に1店舗のみアクセスできます。複数店舗を同時に確認したい場合は、別のブラウザタブで同じURLにアクセスし、それぞれ別の店舗にログインしてください。

### Q: 店舗一覧に新しい店舗が表示されない場合は？

**A**: 店舗が正常に登録・契約されているか確認してください。ページをリロード（F5キー）すると最新の情報が反映されます。

## 8. トラブルシューティング

### ログインできない

| 症状 | 対処法 |
|------|--------|
| 「本部IDが存在しません」と表示 | IDが正しいか確認してください |
| 「パスワードが違います」と表示 | パスワードを確認してください。5回失敗するとロックされます |
| ログインボタンが反応しない | ページをリロードしてください |
| 画面が真っ白になる | ブラウザのキャッシュをクリアしてください（Ctrl+Shift+Delete） |

### 店舗一覧が表示されない

| 症状 | 対処法 |
|------|--------|
| 「店舗一覧の取得に失敗しました」と表示 | ネットワーク接続を確認してください |
| 一覧が空（0店舗） | 店舗が未登録の可能性があります。運営管理者に確認してください |
| 契約IDが「—」と表示 | 店舗の契約設定が未完了です。運営管理者に確認してください |

### 店舗にアクセスできない

| 症状 | 対処法 |
|------|--------|
| 「IDまたはパスワードが正しくありません」 | 契約IDとパスワードを再確認してください |
| 「エラーが発生しました」 | ネットワーク接続を確認し、もう一度お試しください |
