# ラクシフトAI サービス概要資料

**AI × 数理最適化で、シフト作成をもっとラクに。**

---

## ラクシフトAIとは

ラクシフトAIは、飲食店・小売店向けの **AI搭載シフト自動作成サービス** です。

店舗のルール、スタッフの希望、人員要件をAIが総合的に判断し、最適なシフト表をワンクリックで自動生成します。これまで数時間かかっていたシフト作成業務を、わずか数分に短縮します。

---

## 解決する課題

| 解決策 | 効果 |

| AI自動生成 | シフト作成時間を **最大90%削減** |

## 主な機能

### 1. AIシフト自動生成

ラクシフトAI最大の特長です。数理最適化エンジン（混合整数線形計画法）とAI（Google Gemini）の2段階処理により、高精度なシフト表を自動生成します。

**考慮する要素：**
- スタッフの希望休・出勤希望
- 役職・スキル評価（A/B/C/D）
- 週あたりの最大勤務日数・1日の最大勤務時間
- 曜日・時間帯ごとの最低人数
- マネージャー配置・新人教育ペアリング
- 人件費の最適化

**生成対象：** 来週分 / 今月分 / 任意期間

```
スタッフの希望  ─┐
店舗ルール    ─┤→  数理最適化  →  AI監査・修正  →  最適シフト表
人員要件     ─┘    (PuLP)       (Gemini AI)
```

---

### 2. シフト表の表示・編集

| 表示モード | 説明 |
|---|---|
| テーブル表示 | 横軸=時間軸のガントチャート形式。1週間/2週間/1ヶ月の切替可能 |
| カレンダー表示 | 月間カレンダー形式。日付ごとの出勤者を一覧表示 |

- 役職ごとの色分け表示（マネージャー=紫、リーダー=青 等）
- 15分単位の精密な時間管理
- クリック操作で直感的にシフトを追加・編集・削除
- カレンダーへのメモ機能（団体予約・イベント等の記録）

---

### 3. スタッフ管理

| 機能 | 説明 |
|---|---|
| スタッフ登録 | 氏名・役職・評価・給与形態・時給/月給の登録 |
| 勤務制限設定 | 週最大勤務日数・1日最大勤務時間の個別設定 |
| 出勤不可日管理 | 特定日の出勤不可設定。希望休承認時に自動反映 |
| 評価ランク | A/B/C/D の4段階評価。シフト配置の優先度に反映 |

---

### 4. 希望・申請管理

スタッフからの申請を一元管理し、シフト生成に自動反映します。

| 申請種別 | 説明 |
|---|---|
| 希望休 | 休みたい日の申請。承認後、自動生成時に自動除外 |
| 出勤希望 | 出勤したい日の申請 |
| 休暇申請 | 長期休暇の申請 |

**承認ワークフロー：**

```
スタッフが申請  →  管理者が確認  →  承認 or 却下
                                     ↓（承認時）
                               出勤不可日に自動反映
                                     ↓
                           次回シフト生成で自動除外
```

---

### 5. 店舗設定

店舗ごとの運営ルールを細かく設定できます。

| 設定項目 | 内容 |
|---|---|
| 営業時間 | 平日/休日/祝日ごとに個別設定可能 |
| 定休日 | 曜日指定 |
| 最低人数 | 平日/休日/祝日ごとの最低出勤人数 |
| 時間帯別ルール | 例：ランチ帯（11:00〜14:00）は3名以上 |
| 役職定義 | 役職名・色の自由設定 |
| シフトパターン | テンプレート登録（早番・遅番・通し 等） |
| 休憩ルール | 勤務時間に応じた自動休憩計算 |
| AI設定 | 利用するAIモデルの選択 |

---

### 6. 分析・レポート

| 機能 | 説明 |
|---|---|
| 人件費グラフ | 直近30日間の人件費推移をチャート表示 |
| 人件費内訳 | 時給スタッフ・月給スタッフ別のコスト表示 |
| 月間人件費合計 | 当月の総人件費をリアルタイム表示 |
| スタッフ稼働率 | 各スタッフの稼働日数割合 |
| PDF出力 | シフト表を印刷用PDFとして出力 |

## 技術的な強み

### 2段階AI最適化エンジン

従来のシフト作成ツールとの違いは、**数理最適化 + AI監査** の2段階アプローチです。

| 段階 | 技術 | 役割 |
|---|---|---|
| 第1段階 | 数理最適化（混合整数線形計画法） | 数学的に最適なシフト配置を高速計算 |
| 第2段階 | AI監査（Google Gemini） | 人間的な観点で結果を検証・微調整 |

**3段階フォールバック：** 最適解が見つからない場合も、段階的に制約を緩和し、必ず実用的なシフト表を出力します。

### マルチテナントSaaS設計

- 店舗ごとにデータを完全分離
- 1つのシステムで複数店舗を管理可能
- データベースレベルでのセキュリティ（Row Level Security）

---

## セキュリティ

| 項目 | 対策 |
|---|---|
| パスワード | bcryptによる暗号化ハッシュ保存 |
| データ分離 | データベースレベルでのテナント分離（RLS） |
| AIのAPIキー | サーバーサイドでのみ使用（ブラウザに非公開） |
| 通信 | HTTPS暗号化通信 |

## システム構成

```
        ユーザー（ブラウザ）
              │
     ┌────────┼────────┐
     │        │        │
     v        v        v
  Supabase  Cloud    AI API
 (データ)   Run    (Gemini /
 PostgreSQL (最適化)  OpenAI)
```

| コンポーネント | 役割 |
|---|---|
| フロントエンド | Webブラウザで動作するUI |
| Supabase | データベース・認証・API基盤 |
| Cloud Run（Python） | シフト最適化エンジン |
| Gemini / OpenAI API | AI監査・制約チェック |
