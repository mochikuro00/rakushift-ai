# ラクシフトAI サービス概要資料

> 最終更新: 2026年6月3日 (v3.7.27)

---

## サービス名
**ラクシフトAI** — AIシフト自動生成クラウドサービス

---

## コンセプト
「**シフト作成を、AIに任せよう。**」

飲食店・小売店・医療介護施設のシフト管理を、数理最適化AIとGemini AIの二段構えで完全自動化。
日本の労働基準法を遵守しながら、最適な人員配置を瞬時に生成します。

---

## 対象ユーザー

| 業種 | 課題 |
|------|------|
| 飲食店（カフェ、レストラン） | 早番/遅番/ランチ/ディナーの複雑なシフト |
| 小売店（コンビニ、アパレル） | パート・アルバイトの希望休調整 |
| 医療・介護施設 | 夜勤・日勤ローテーション |
| オフィス | シフト制勤務のコスト最適化 |

---

## 主要機能一覧

### 🤖 AIシフト自動生成
- 数理最適化エンジン（PuLP/MILP）が最適解を計算
- Gemini AIが労働基準法チェック＆最終監査
- **プレビュー機能**: 生成結果を確認してから保存
- **イレギュラーシフト警告**: 人員不足による強制配置箇所を赤枠で可視化
- **カバレッジ最適化 (±0 ぴったり配置)**: 過剰配置/不足配置の両方を強くペナライズし、必要人員ピッタリに合わせる (v3.7.27 で COVERAGE_OVER 4M → 8M に強化)
- **希望シフト最大尊重**: EXACT 一致 -3M / 近似 -2M / 一部一致 -1.5M の3段階ボーナスで本人希望を最優先

### 📊 シフト管理
- ガントチャート表示（ドラッグ&ドロップ対応）
- カレンダー/リスト/テーブルの3ビュー切替
- シフト印刷機能
- カレンダーメモ機能

### 👥 スタッフ管理
- 役職管理（店長/リーダー/スタッフ/新人）
- 評価制度（A～D）
- 勤務条件設定（1日の最大時間・週の最大日数）
- **最低出勤日数の保証**（週/月の最低日数を設定可能、v3.7.18 以降はソフト制約として柔軟運用）
- **希望時間考慮トグル**（社員は穴埋め対応、バイトは希望通りなど柔軟設定）
- **需給バランス警告バナー** (v3.7.25): 全員の月最低出勤日数の合計 vs 月間需要を表示し、登録過剰を一目で検知
- **土日希望時間 自動補完** (v3.7.26): 時給制スタッフで土日希望が空欄なら平日希望時間を自動コピー
- **時間入力 UI 改善** (v3.7.27): キーボード打ち込み対応 (`<input type="time">`)

### 📋 休み希望管理
- スタッフがカレンダーから複数日選択→申請
- 管理者が承認/却下
- 承認済みの休みはAI生成時に自動除外

### ⚙️ 店舗設定
- 営業時間、定休日、臨時休業日
- シフトパターン設定（早番/遅番等）
- **プリセット一括適用**（飲食店/オフィス/小売店/医療の4種）
- 時間帯別・曜日別の必要人員設定
- 休憩ルール設定

### 🔐 セキュリティ
- 店舗パスワード変更機能
- マスターパスワード（運営者用フォールバック）
- bcryptハッシュ、RLS、CORS制限、レート制限

### 💳 決済・課金
- Stripe決済（クレジットカード）
- 3プラン（Standard / Pro / Premium）
- 自動テナント作成、ウェルカムメール送信

### 📢 お知らせ機能
- 運営→全店舗へのお知らせ配信
- ログイン前・ログイン後の両方で表示

## 労働基準法準拠

| 条文 | 制約 |
|------|------|
| 第32条 | 1日8時間・週40時間以内 |
| 第34条 | 6h超→45分、8h超→60分の休憩 |
| 第35条 | 週1日以上の休日（連続6日まで） |
| (追加) | 勤務間インターバル 10時間以上 |

これらは全てAIエンジンに組み込まれ、**自動で遵守**されます (HARD 制約)。

## 変更履歴 (v3.7.16〜v3.7.27 / 2026-06)

### 廃止された機能
シフト生成アルゴリズムをカバレッジ重視・希望シフト尊重に再設計するため、以下の機能を削除しました。

- 戦力バランス制約 (スタッフのスキル合計を一定に揃える)
- ピーク帯スキルミックス制約 (ピーク時間帯にベテラン優先)
- 連続5日後の疲労インセンティブ (5日連勤後の翌日休み誘導)
- 土日ローテーション公平性 (土日出勤を全員均等に)
- 時間帯分散制約 (朝/昼/夕の3区分でバランス)
- 管理者常駐制約 → 「社員1名以上常駐」に変更
- NGペア制約 (アルゴリズム + UI)
- 人件費×評価ランク最小化
- 月給スタッフ強制出勤ペナルティ

### 緩和された制約
- 最低出勤日数 (週/月): ハード → ソフト化 (達成しなくても罰金で済む柔軟運用)
- OJT 制約: 大幅に弱化 (3M → 500k)
- evaluation=="D" のスタッフは新人扱いから除外

### 追加された機能
- 需給バランス警告バナー
- 土日希望時間 自動補完
- 時間入力 UI 改善 (打ち込み対応)
- カバレッジ過剰配置の根本解決 (ぴったり配置を実現)
